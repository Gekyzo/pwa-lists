# Notes de version

Ce qui change pour vous dans chaque version de l’app. La version la plus récente vient en premier.

- Tu te connectes avec ton compte Google, ou tu touches **Utiliser hors connexion** pour utiliser l’application sans compte. L’administrateur approuve chaque nouveau compte. Tes listes restent sur cet appareil.

## 1.0.3 - 2026-10-24

- `Réglages` › `Aide` › `Nouveautés` montre ce qui change dans chaque version. Après une mise à jour, la page s’ouvre une fois toute seule.
