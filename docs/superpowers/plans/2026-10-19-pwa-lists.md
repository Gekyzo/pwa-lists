# pwa-lists Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make pwa-lists a copy of Bodega with no recipes, no menu and no recurrent items, safe to run beside Bodega on the same origin.

**Architecture:** Copy the tracked files of `../pwa-shopping-list` at `1ba991e` into this repository, make it green under its new identity, then remove one feature per task. Each task keeps `npm test` green and changes `docs/spec/` with the code (the `pre-commit` hook, ENG-13).

**Tech Stack:** Plain HTML, CSS, ES modules, `node:test` (Node 20+). No build step, no dependency.

**Spec:** `docs/superpowers/specs/2026-10-19-pwa-lists-design.md`

## Global Constraints

- `localStorage` prefix `lists.`; caches `lists-shell-v1` and `lists-manifest`; the activate of `sw.js` deletes only caches that start with `lists-`.
- Manifest `id` `/pwa-lists/`; name and short name `Listas`; deploy URL `https://gekyzo.github.io/pwa-lists/`.
- State `{ version: 10, items, group, sort, aisles }`; item `{ id, name, list, bought, shops, quantity, aisle }`; `GROUPS = ['shop', 'aisle', 'none']`; default group `shop`.
- Load and import read versions 1 to 10; the stored state is version 10.
- Commit messages: imperative, capitalised, no prefix, no period, no attribution (GIT.md). A behaviour change has a body.
- Removed rules in kept spec documents become `- **X-N** Removed: <reason>.` lines. `06-recipes.md`, `13-menu.md` and the `REC`, `MENU` prefixes are deleted.
- No release, no tag, no push.

## Review Focus

- A Bodega v9 backup with recipes, `sent`, a menu and recurrent items imports with no error, and the items keep their names, shops, quantity and aisle (Task 5).
- A Bodega backup with `group: 'recipe'` imports as `group: 'shop'` (Task 5).
- A state stored by a build of this repo before Task 5 (version 9 under `lists.v1`) still loads (Task 5).
- The activate of `sw.js` keeps a cache named `shopping-shell-v17` (Task 1).
- No locale keeps a key that no code uses: `tests/i18n.test.js` parity plus a grep for `receta|recipe|menú|repetir|↻` in `src/` (Task 6).
