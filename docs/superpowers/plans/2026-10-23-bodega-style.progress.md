# Bodega style — Progress

Companion to [`2026-10-23-bodega-style.md`](2026-10-23-bodega-style.md). Generated by `~/.claude/scripts/plan-current.sh companion`
when the plan was written; re-synced whenever the plan's `### Task N` headers change.

**The one rule: this file is updated in the same commit as the task it records.** A task
goes ◐ when it starts (`plan-current.sh task N start`) and ☑ in the commit that lands it
(`plan-current.sh task N land`, staged with the work). Bound that way, `git log -p` on this
file reads as the history of the plan actually happening.

The Commit column holds the commit's **subject line**, not its sha — a sha cannot name the
commit it rides in. `git log --oneline --grep` finds the sha from it.

While this plan is executing, `current-plan.progress.md` in this directory points here, and
the 🎯 indicators (terminal status bar, tab ring, overlord tile) draw from this table.
